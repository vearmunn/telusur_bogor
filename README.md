# Telusur Bogor

Telusur Bogor is a travel companion application designed to help users explore Bogor, Indonesia. The app brings together destination discovery, weather information, transportation routes, emergency resources, maps, and trip planning into a single application.

## Features

* 🌤️ **Weather Information** — Check the current temperature and weather conditions in Bogor.
* 📍 **Destination Discovery** — Explore popular destinations, nearby destinations, and lesser-known "secret gems" around Bogor.
* 🚌 **Angkot Routes** — View angkot routes to help users navigate Bogor using local public transportation.
* 🚨 **Emergency Contacts** — Quickly access important emergency contact information.
* 🏥 **Nearby Help** — Find nearby essential services such as police stations, fire stations, hospitals, and other helpful locations.
* 🗺️ **Map** — Explore destinations and important locations through an interactive map.
* ❤️ **Favorite Places** — Save destinations to a personal list of favorite places.
* 🧳 **Trip Boards** — Create and organize trip plans for places you want to visit.

## Tech Stack

* **Flutter**
* **Dart**
* **OpenStreetMap** — Map and location data
* **OSRM** — Route calculation
* **Firebase** — Authentication and cloud services
* **Weather API** — Weather information
* **GetX / State Management**

## Overview

The goal of Telusur Bogor is to create a convenient travel companion specifically for people exploring Bogor.

Instead of relying on multiple applications for weather, maps, transportation information, emergency services, and trip planning, Telusur Bogor aims to bring these features together in one application.

The project also focuses on helping users discover destinations beyond the most commonly visited tourist attractions by highlighting nearby locations and lesser-known destinations.

## Project Status

🚧 **Work in Progress**

Telusur Bogor is an unfinished project. Some features are implemented and functional, while others are still in the planning or concept stage.

The project was developed as a learning and portfolio project, and development may resume in the future.
